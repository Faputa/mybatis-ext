# 变更记录

## 0.0.18

### 新增功能

- 新增 IDEA 插件，提供 MyBatis XML 编辑支持，以及实体映射检查、方法名 CRUD 诊断、补全、导航和 SQL 预览。
- 新增共享核心分析能力，使 IDEA 插件与运行时使用一致的映射和方法名解析规则。
- 新增 SQL Server 支持，默认适配 SQL Server 2012 及以上版本，并提供 SQL Server 2008 方言。

### 问题修复

- 修复复杂条件中 `AND` / `OR` 优先级、分组取反及重复条件的处理，避免动态条件省略后改变查询含义。
- 修复 `Top`、`Limit`、`Having` 与普通条件混用时的参数绑定顺序，正确处理 MyBatis 参数别名及特殊参数，并避免同一参数的不同转换和 JDBC 类型相互覆盖。
- 修复无参、基本类型及包装类型方法重载的 SQL 匹配问题，避免重载方法遗漏或匹配错误的 SQL。
- 修复仅在 `HAVING` 中引用关联表时缺失 JOIN 的问题。
- 修复不同路径下同名嵌套属性的查询和结果映射冲突，避免复用错误的嵌套映射。
- 修复不同 MyBatis 配置之间的缓存干扰，避免默认过滤策略及 TypeHandler 等配置相互影响。
- 修复数组参数的批量增删改识别，以及基本类型数组的 OGNL 空值判断和模板取值问题。
- 修复 UUID 和自定义主键生成时的参数传递，保留调用方已设置的主键值。
- 修复 Spring 中混合存放 `SqlSessionFactory` 与其他类型值的 Map Bean 在增强时发生类型转换异常的问题。

### 构建与兼容性

- 统一使用 Gradle 多模块构建，保留原 Maven 坐标。
- 核心及 Spring 模块保持 Java 8 兼容；IDEA 插件支持 IDEA 2023.3 至 2026.3，最低要求 Java 17。
